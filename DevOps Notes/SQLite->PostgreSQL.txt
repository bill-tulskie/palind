Steps to convert Django app from SQLite to PostgreSQL


1. Back Up Existing Data
Before changing anything, export your current SQLite data into a JSON fixture file.
Exclude contenttypes and auth.Permission data. Django automatically regenerates these records during the migration phase, and trying to re-import them manually causes severe database conflict errors.

python manage.py dumpdata --natural-foreign --natural-primary -e contenttypes -e auth.Permission --indent 4 > datadump.json

2. Install Database Adapter
Django requires a database adapter package to communicate with PostgreSQL. Install the binary version of psycopg (formerly known as psycopg2)

pip install psycopg2-binary

3. Update Django Settings
Open your settings.py file (in /palind/backend/palind/settings.py) and swap your DATABASES setting from the SQLite configuration to your PostgreSQL parameters.

Old Configuration (SQLite):

PYTHON
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}

New Configuration (PostgreSQL):
Instead of hardcoding your database password directly in the file, pull the connection values safely from environment variables:

TODO: The connection values are not being set currently for the environment.  Needs research/update.

PYTHON
import os

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': os.getenv('DB_NAME', 'your_db_name'),
        'USER': os.getenv('DB_USER', 'your_db_user'),
        'PASSWORD': os.getenv('DB_PASSWORD', 'your_db_password'),
        'HOST': os.getenv('DB_HOST', 'localhost'),
        'PORT': os.getenv('DB_PORT', '5432'),
    }
}

4. Create the Tables (Schema)
Before you can fill your PostgreSQL database with data, you must instruct Django to execute its existing migrations to build out the correct table schema:

bash
cd [project root] (e.g. /Users/bill/Projects/GitHub/palind/backend)
(.venv) python manage.py migrate

5. Load the Exported Data
With the target database schema initialized, push your JSON file records into PostgreSQL:

bash
python manage.py loaddata data-dumps/datadump-2026-07-24.json
